Раздел 1. Основы языка Kotlin и среда разработки

1.1. История и место Kotlin в экосистеме мобильной разработки

Kotlin — статически типизированный язык программирования, разработанный компанией JetBrains и впервые представленный в 2011 году [1]. В 2017 году Google объявила Kotlin официальным языком разработки для Android, а в 2019 году — приоритетным (Kotlin-first). Kotlin компилируется в байт-код JVM, но также поддерживает компиляцию в JavaScript (Kotlin/JS) и в нативный код (Kotlin/Native), что делает его мультиплатформенным языком [2].

Ключевые причины популярности Kotlin в мобильной разработке:

  • Полная совместимость с Java: Kotlin-код может вызывать Java-код и наоборот, что позволяет постепенно мигрировать существующие проекты;
  • Лаконичность: объём кода сокращается на 30–40% по сравнению с Java за счёт отсутствия обязательных геттеров/сеттеров, вывода типов, свойств вместо полей;
  • Null-безопасность: система типов на уровне компилятора предотвращает большинство ошибок NullPointerException;
  • Функциональные возможности: лямбда-выражения, функции высшего порядка, функции-расширения, корутины;
  • Официальная поддержка инструментов: Android Studio, Jetpack-библиотеки, Jetpack Compose ориентированы в первую очередь на Kotlin [3].

1.2. Переменные, типы данных и вывод типов

В Kotlin переменные объявляются двумя способами [4]:

  • val (value) — неизменяемая ссылка (аналог final в Java), после инициализации значение нельзя переприсвоить;
  • var (variable) — изменяемая ссылка.
val name: String = "Kotlin"   // неизменяемая
var counter: Int = 0          // изменяемая
counter = 10                  // допустимо
// name = "Java"              // ошибка компиляции

Kotlin — язык со статической типизацией, но компилятор умеет выводить тип из контекста:

val pi = 3.14          // тип Double выведен автоматически
val greeting = "Hi"    // тип String

Базовые типы: Byte, Short, Int, Long, Float, Double, Boolean, Char, String. Все они являются объектами (не примитивами), но компилятор оптимизирует их до примитивов JVM там, где это возможно.

Строковые шаблоны позволяют встраивать выражения в строки:

val age = 20
println("Возраст: $age, через год: ${age + 1}")

1.3. Null-безопасность

Одна из главных особенностей Kotlin — разделение типов на nullable (String?) и non-nullable (String). Переменная non-nullable типа не может содержать null, и компилятор это гарантирует.

var a: String = "text"
// a = null            // ошибка компиляции
var b: String? = "text"
b = null               // допустимо

Для работы с nullable-типами предусмотрены операторы:

ОператорНазначениеПример
?.Безопасный вызов: возвращает null, если объект nullb?.length
?:Эливис-оператор: значение по умолчаниюb?.length ?: 0
!!Принудительное разыменование (бросает NullPointerException)b!!.length
as?Безопасное приведение типаobj as? String
val length: Int = b?.length ?: 0   // безопасно
val len2 = b!!.length              // опасно, может упасть

Оператор !! следует применять только тогда, когда программист абсолютно уверен в ненулевости значения; в противном случае предпочтительны ?. и ?:.

1.4. Управляющие конструкции

Условия: if в Kotlin — это выражение, возвращающее значение: val max = if (a > b) a else b.

Конструкция when заменяет switch и работает с любыми типами, диапазонами и условиями:

fun describe(x: Any): String = when (x) {
    1 -> "единица"
    in 2..10 -> "от 2 до 10"
    is String -> "строка длиной ${x.length}"
    else -> "неизвестно"
}

Циклы: for работает с диапазонами и коллекциями; while и do-while — как в Java:

for (i in 1..5) println(i)          // 1,2,3,4,5
for (i in 5 downTo 1 step 2) println(i)  // 5,3,1

1.5. Функции

Объявление функций. Функции в Kotlin объявляются ключевым словом fun. Минимальный синтаксис: fun имя(параметры): ВозвращаемыйТип { тело }. Если функция состоит из одного выражения, используется сокращённая форма с = (expression body), при которой тип возвращаемого значения выводится компилятором. Kotlin поддерживает параметры по умолчанию (значение задаётся прямо в сигнатуре и может быть опущено при вызове) и именованные аргументы (при вызове можно указать имя = значение, что повышает читаемость и позволяет передавать аргументы в произвольном порядке) [5]:

fun greet(name: String = "мир"): String = "Привет, $name!"

greet()                    // Привет, мир!
greet(name = "Kotlin")     // Привет, Kotlin!

Функции-расширения. Это функции, объявленные вне класса, но вызываемые так, как будто они являются его методами. В сигнатуре перед именем функции указывается тип-получатель: fun String.shout(). Внутри такой функции доступен объект-получатель this, ссылающийся на экземпляр, для которого вызвано расширение. Расширения позволяют добавлять новую функциональность к существующим классам (в том числе к классам из сторонних библиотек и к стандартным типам) без наследования и без изменения исходного кода. Важно понимать: расширения разрешаются статически — компилятор выбирает нужную функцию по объявленному типу переменной, а не по фактическому типу объекта во время выполнения:

fun String.shout(): String = this.uppercase() + "!"
println("kotlin".shout())   // KOTLIN!

Инфиксные функции. Функция, помеченная словом infix, может вызываться в форме a имя b без точки и скобок. Такая запись используется для операций, читаемых как естественный язык (например, 1 to 2, user name "Иван"). Требования: функция должна быть членом класса или расширением, иметь ровно один параметр, и параметр не должен быть vararg или иметь значение по умолчанию.

Лямбда-выражения. Лямбда — это безымянная функция, которую можно передавать как значение, хранить в переменной и возвращать из других функций. Синтаксис: { параметры -> тело }. Если параметр один, его можно не объявлять и обращаться к нему через неявное имя it. Лямбды — основа функционального стиля: они позволяют передавать поведение в функцию (например, условие фильтрации или правило преобразования) вместо написания отдельных классов и методов. Лямбда замыкает переменные из окружающей области видимости, то есть захватывает их значения:

val square: (Int) -> Int = { x -> x * x }
val isEven: (Int) -> Boolean = { it % 2 == 0 }

Функции высшего порядка. Это функции, которые принимают другие функции в качестве параметров и/или возвращают функцию как результат. Они позволяют абстрагировать повторяющиеся алгоритмы (обход, фильтрация, преобразование, агрегация) и передавать конкретное поведение через лямбду. В примере ниже operate принимает два числа и функцию op, задающую операцию:

fun operate(a: Int, b: Int, op: (Int, Int) -> Int): Int = op(a, b)
val sum = operate(2, 3) { x, y -> x + y }   // 5
val mul = operate(2, 3) { x, y -> x * y }   // 6

1.6. Классы и объекты

Kotlin поддерживает классы, data-классы, sealed-классы, объекты-синглтоны и companion-объекты.

Обычные классы. Класс объявляется словом class; его свойства можно задавать прямо в первичном конструкторе через val (только чтение) или var (чтение и запись). В теле класса можно объявлять дополнительные свойства, методы, инициализаторы (init) и вторичные конструкторы. Обычный класс удобен для описания сущностей с поведением (например, Person с методами и изменяемыми полями):

class Person(val name: String, var age: Int) {
    fun birthday() { age++ }
}

Data-классы. Data-класс (data class) — это класс, главное назначение которого — хранить набор данных. Компилятор автоматически генерирует для него методы equals/hashCode (сравнение по содержимому, а не по ссылке), toString (читаемое представление), copy (создание копии с изменением отдельных полей) и componentN (деструктуризация). Data-классы удобны для моделей данных, DTO, элементов UI-состояния и ключей в коллекциях. Требования: первичный конструктор должен содержать хотя бы один параметр, помеченный val/var:

data class Point(val x: Int, val y: Int)

val p = Point(1, 2)
val q = p.copy(y = 5)          // Point(x=1, y=5)
val (x, y) = p                 // деструктуризация
println(p == Point(1, 2))      // true — сравнение по содержимому

Sealed-классы. Sealed-класс (sealed class) описывает закрытую иерархию: все его наследники должны быть объявлены в том же файле (а с Kotlin 1.5 — в том же пакете/модуле). Это даёт компилятору полный список возможных подтипов, поэтому в when по sealed-классу можно не писать ветку else — компилятор проверит исчерпывающность обработки. Sealed-классы идеально подходят для моделирования состояний (загрузка / успех / ошибка), результатов операций и событий:

sealed class Result
class Success(val data: String) : Result()
class Error(val message: String) : Result()

fun handle(r: Result) = when (r) {
    is Success -> println("OK: ${r.data}")
    is Error -> println("Ошибка: ${r.message}")
}   // ветка else не нужна — все случаи покрыты

Объекты-синглтоны и companion-объекты. Конструкция object объявляет объект в единственном экземпляре (синглтон) — удобно для утилит, репозиториев без состояния, фабрик. companion object — это объект, связанный с классом: его члены доступны через имя класса (аналог статических членов в Java). Companion-объекты часто используются для фабричных методов и констант:

object AppConfig { const val BASE_URL = "https://api.example.com/" }

class User private constructor(val id: Int) {
    companion object {
        fun create(id: Int) = User(id)
    }
}
val u = User.create(1)   // доступ через имя класса

Свойства с кастомными геттерами и сеттерами. Свойство можно объявить в конструкторе или в теле класса. Для него разрешено определять собственный геттер (get()) и, если свойство изменяемое, сеттер (set(value)). Вычисляемые свойства (без поля-хранилища) удобны для производных величин, например площади:

class Rectangle(val width: Int, val height: Int) {
    val area: Int
        get() = width * height
}

1.7. Коллекции и функциональная обработка

Immutable и mutable коллекции. Kotlin на уровне типов разделяет коллекции только для чтения (List, Set, Map) и изменяемые (MutableList, MutableSet, MutableMap). Интерфейс List не содержит методов add/remove, поэтому функция, принимающая List, не может изменить переданную коллекцию — это повышает безопасность и предсказуемость кода. Изменяемые версии добавляют методы модификации. Фабрики listOf(), setOf(), mapOf() создают коллекции только для чтения, а mutableListOf(), mutableSetOf(), mutableMapOf() — изменяемые. При необходимости неизменяемую коллекцию можно преобразовать в изменяемую через toMutableList().

Назначение разных типов коллекций:

  • List — упорядоченная последовательность с доступом по индексу и возможными дубликатами; подходит для списков элементов UI, результатов запросов;
  • Set — неупорядоченное множество уникальных элементов; используется для проверки принадлежности, устранения дубликатов;
  • Map — набор пар «ключ–значение» с уникальными ключами; применяется для словарей, индексов, кэшей (associateBy).

Функции высшего порядка для обработки коллекций. Kotlin предоставляет богатый набор декларативных операций, которые принимают лямбды. Это позволяет описывать что нужно получить, а не как это делать циклом. Основные группы:

  • преобразование: map (применяет функцию к каждому элементу), flatMap (преобразует каждый элемент в коллекцию и «разворачивает» результат в один список), zip (объединяет две коллекции в список пар);
  • фильтрация: filter (оставляет элементы, удовлетворяющие предикату), filterNot, find (первый подходящий элемент или null), distinct (убирает дубликаты);
  • агрегация: reduce (сворачивает коллекцию, начиная с первого элемента), fold (сворачивает с заданным начальным значением), sum, average, count, maxOrNull, minOrNull;
  • проверки: any (есть ли хотя бы один подходящий), all (все ли подходят), none (ни один не подходит);
  • группировка и сортировка: groupBy (строит Map из групп по ключу), sortedBy/sortedByDescending (сортировка по вычисляемому ключу), associateBy (строит Map по ключу из элементов).
val nums = listOf(1, 2, 3, 4, 5, 6)

val squaresOfEvens = nums.filter { it % 2 == 0 }.map { it * it }  // [4, 16, 36]
val total = nums.reduce { acc, x -> acc + x }                     // 21
val totalFrom100 = nums.fold(100) { acc, x -> acc + x }           // 121
val hasNegative = nums.any { it < 0 }                             // false
val allPositive = nums.all { it > 0 }                             // true
val byParity = nums.groupBy { it % 2 == 0 }                       // {false=[1,3,5], true=[2,4,6]}
val pairs = listOf("a", "b").zip(listOf(1, 2))                    // [(a,1), (b,2)]

Цепочки операций. Функции высшего порядка можно объединять в цепочки; при этом промежуточные коллекции создаются лениво только при необходимости. Для больших коллекций применяются последовательности (asSequence()), которые обрабатывают элементы по одному без создания промежуточных списков:

val result = (1..1_000_000).asSequence()
    .filter { it % 2 == 0 }
    .map { it * it }
    .take(5)
    .toList()   // [4, 16, 36, 64, 100]

1.8. Среда разработки Android Studio

Android Studio — официальная IDE для Android-разработки, основанная на IntelliJ IDEA. Основные компоненты:

  • Gradle — система сборки; конфигурация проекта описывается в build.gradle.kts;
  • SDK Manager — управление версиями Android SDK и инструментами;
  • AVD Manager — создание виртуальных устройств (эмуляторов);
  • Logcat — просмотр системных логов;
  • Layout Inspector — анализ UI в реальном времени.

Минимальный проект содержит: AndroidManifest.xml (описание приложения), MainActivity.kt (точка входа), res/ (ресурсы), build.gradle.kts (зависимости).

Контрольные вопросы

1. Чем val отличается от var?

Показать правильный ответ
Ответ: val нельзя изменить после присваивания, var — можно.

2. Что делает оператор ?.?

Показать правильный ответ
Ответ: Безопасно вызывает метод: если объект null, вернёт null, а не ошибку.

3. Что делает оператор ?:?

Показать правильный ответ
Ответ: Возвращает значение по умолчанию, если слева null.

4. Что такое функция-расширение?

Показать правильный ответ
Ответ: Функция, которую можно вызывать как метод класса, не меняя сам класс.

5. Чем List отличается от MutableList?

Показать правильный ответ
Ответ: List нельзя изменить (нет add/remove), MutableList — можно.

6. Что такое data-класс?

Показать правильный ответ
Ответ: Класс для хранения данных; сам создаёт equals, hashCode, toString, copy.

Упражнения для самостоятельной работы

Упражнение 1. Напишите функцию, которая из списка чисел оставляет только чётные и возводит их в квадрат.

Показать пример решения 
fun evenSquares(numbers: List<Int>): List<Int> =
    numbers.filter { it % 2 == 0 }.map { it * it }

fun main() {
    println(evenSquares(listOf(1, 2, 3, 4, 5)))  // [4, 16]
}

Упражнение 2. Создайте класс User с полями name и age (возраст может быть null). Выведите имя и возраст, обработав null.

Показать пример решения 
class User(val name: String, val age: Int?)

fun printUser(u: User) {
    val ageText = u.age?.toString() ?: "не указан"
    println("${u.name}: $ageText")
}

fun main() {
    printUser(User("Иван", 25))     // Иван: 25
    printUser(User("Мария", null))  // Мария: не указан
}

Упражнение 3. Напишите функцию-расширение для String, которая переворачивает строку.

Показать пример решения 
fun String.reverseWords(): String = this.split(" ").reversed().joinToString(" ")

fun main() {
    println("Kotlin is great".reverseWords())  // great is Kotlin
}
