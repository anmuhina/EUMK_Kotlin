Раздел 2. Разработка пользовательского интерфейса (Jetpack Compose)

2.1. От императивного UI к декларативному

Традиционный подход Android (Views/XML) — императивный: разработчик создаёт дерево View и вручную изменяет его свойства при изменении данных (textView.text = ...). Это приводит к рассинхронизации состояния и UI, а также к большому количеству шаблонного кода.

Jetpack Compose — декларативный UI-фреймворк, представленный Google в 2021 году. В Compose интерфейс описывается функциями, помеченными аннотацией @Composable, а UI автоматически перестраивается при изменении состояния. Формула декларативного подхода: UI = f(state). Разработчик описывает, как UI должен выглядеть при данном состоянии, а фреймворк сам вычисляет минимальные изменения [3].

Преимущества Compose:

  • меньше кода и отсутствие XML-разметки;
  • естественная реактивность: изменение состояния автоматически обновляет UI;
  • компонентность и переиспользуемость;
  • поддержка анимаций, тем, адаптивных layouts «из коробки»;
  • единый язык (Kotlin) для логики и UI.

2.2. Composable-функции и рекомпозиция

Composable-функция — обычная функция с аннотацией @Composable. Она не возвращает View, а описывает элемент UI:

@Composable
fun Greeting(name: String) {
    Text(text = "Привет, $name!")
}

Рекомпозиция — повторный вызов composable-функции при изменении читаемого ею состояния. Compose отслеживает, какие функции читают какие состояния, и перезапускает только те, чьи зависимости изменились (так называемая «умная рекомпозиция»). Это обеспечивает высокую производительность.

Важное правило: composable-функции должны быть чистыми (без побочных эффектов). Для побочных эффектов (сетевые запросы, подписки) используются LaunchedEffect, DisposableEffect, SideEffect.

2.3. Состояние: remember и mutableStateOf

Состояние в Compose — это объект, изменение которого вызывает рекомпозицию. Базовый механизм:

@Composable
fun Counter() {
    var count by remember { mutableStateOf(0) }
    Column {
        Text("Счётчик: $count")
        Button(onClick = { count++ }) { Text("+1") }
    }
}
  • mutableStateOf(x) создаёт наблюдаемое состояние.
  • remember { ... } сохраняет объект между рекомпозициями.
  • by — делегирование свойства (требует импорта getValue/setValue).

Для состояния, которое должно переживать смену конфигурации (поворот экрана), используется rememberSaveable.

Подъём состояния (state hoisting) — рекомендуемый паттерн: состояние поднимается в родительский composable, а дочерние получают значение и колбэк изменения. Это делает компоненты переиспользуемыми и тестируемыми.

@Composable
fun Parent() {
    var text by remember { mutableStateOf("") }
    Child(value = text, onValueChange = { text = it })
}

@Composable
fun Child(value: String, onValueChange: (String) -> Unit) {
    TextField(value = value, onValueChange = onValueChange)
}

2.4. Базовые компоненты и компоновки

Основные UI-элементы: Text, Button, TextField, Image, Icon, Checkbox, Switch, Slider, Card.

Компоновки (layout):

  • Row — горизонтальное расположение;
  • Column — вертикальное;
  • Box — наложение элементов друг на друга;
  • LazyColumn / LazyRow — ленивые списки (создают только видимые элементы, что критично для больших списков);
  • ConstraintLayout — сложные ограничения (аналог XML ConstraintLayout).
LazyColumn {
    items(users) { user ->
        ListItem(
            headlineContent = { Text(user.name) },
            supportingContent = { Text(user.email) }
        )
    }
}

Модификаторы (Modifier) управляют размерами, отступами, фоном, кликабельностью:

Text(
    "Заголовок",
    modifier = Modifier
        .fillMaxWidth()
        .padding(16.dp)
        .background(Color.LightGray)
)

2.5. Навигация

Навигация в Compose реализуется библиотекой androidx.navigation:navigation-compose. Экраны описываются маршрутами (строками), переходы — через NavController:

val navController = rememberNavController()
NavHost(navController, startDestination = "home") {
    composable("home") {
        Button(onClick = { navController.navigate("details/42") }) { Text("Открыть") }
    }
    composable("details/{id}") { backStackEntry ->
        val id = backStackEntry.arguments?.getString("id")
        Text("Детали: $id")
    }
}

NavHost содержит граф навигации; composable(route) регистрирует экран; navController.navigate(route) выполняет переход; popBackStack() — возврат назад. Аргументы передаются через шаблон маршрута и извлекаются из NavBackStackEntry.

2.6. Темизация и Material Design 3

Compose поддерживает Material Design 3 через MaterialTheme, включающий цветовую схему (colorScheme), типографику (typography) и формы (shapes). Тёмная/светлая тема определяется через isSystemInDarkTheme(). Кастомизация темы выполняется в Theme.kt.

@Composable
fun MyAppTheme(darkTheme: Boolean = isSystemInDarkTheme(), content: @Composable () -> Unit) {
    val colors = if (darkTheme) darkColorScheme() else lightColorScheme()
    MaterialTheme(colorScheme = colors, content = content)
}

2.7. Побочные эффекты и асинхронность в UI

  • LaunchedEffect(key) — запускает корутину при входе в композицию и при изменении ключа.
  • DisposableEffect(key) — выполняет код при входе и очистку при выходе.
  • rememberCoroutineScope() — создаёт CoroutineScope, привязанный к композиции, для запуска корутин из обработчиков.
  • produceState — преобразует асинхронный источник в состояние.
@Composable
fun UserScreen(userId: String) {
    var user by remember { mutableStateOf<User?>(null) }
    LaunchedEffect(userId) {
        user = repository.loadUser(userId)
    }
    user?.let { Text(it.name) }
}

Контрольные вопросы

1. Что такое рекомпозиция?

Ответ: Повторный вызов composable-функции при изменении читаемого ею состояния.

2. Зачем нужен remember?

Показать правильный ответ
Ответ: Сохраняет значение между рекомпозициями, чтобы состояние не сбрасывалось.

3. Чем Column отличается от Row?

Показать правильный ответ
Ответ: Column располагает элементы вертикально, Row — горизонтально.

4. Зачем нужен LazyColumn?

Показать правильный ответ
Ответ: Создаёт только видимые элементы списка — экономит память на больших списках.

5. Какой компонент отвечает за навигацию?

Показать правильный ответ
Ответ: NavHost и NavController из библиотеки navigation-compose.

Упражнения для самостоятельной работы

Упражнение 1. Сделайте экран: поле ввода, кнопка, текст под кнопкой. По нажатию текст из поля появляется в Text.

Показать пример решения 
@Composable
fun SimpleInputScreen() {
    var input by remember { mutableStateOf("") }
    var shown by remember { mutableStateOf("") }
    Column(Modifier.padding(16.dp), verticalArrangement = Arrangement.spacedBy(8.dp)) {
        TextField(value = input, onValueChange = { input = it }, label = { Text("Введите текст") })
        Button(onClick = { shown = input }) { Text("Показать") }
        Text(shown, style = MaterialTheme.typography.headlineMedium)
    }
}

Упражнение 2. Выведите список из 10 элементов через LazyColumn.

Показать пример решения 
@Composable
fun TenItemsList() {
    val items = (1..10).map { "Элемент №$it" }
    LazyColumn {
        itemsIndexed(items) { index, title ->
            ListItem(
                headlineContent = { Text(title) },
                leadingContent = { Text("${index + 1}") }
            )
            HorizontalDivider()
        }
    }
}

Упражнение 3. Сделайте форму с логином и паролем и проверкой: логин не пустой, пароль не короче 6 символов.

Показать пример решения 
@Composable
fun RegistrationForm() {
    var login by remember { mutableStateOf("") }
    var password by remember { mutableStateOf("") }
    var error by remember { mutableStateOf<String?>(null) }

    Column(Modifier.padding(16.dp), verticalArrangement = Arrangement.spacedBy(8.dp)) {
        TextField(login, { login = it }, label = { Text("Логин") })
        TextField(password, { password = it }, label = { Text("Пароль") },
            visualTransformation = PasswordVisualTransformation())
        error?.let { Text(it, color = Color.Red) }
        Button(onClick = {
            error = when {
                login.isBlank() -> "Логин не может быть пустым"
                password.length < 6 -> "Пароль должен быть не короче 6 символов"
                else -> null
            }
        }) { Text("Зарегистрироваться") }
    }
}
