Критерии и шкала оценивания

Каждое задание оценивается по 5-балльной шкале. Итоговая оценка за комплекс — среднее арифметическое по трём заданиям (с округлением до целого).

БаллыКритерий
5Задание выполнено полностью: код компилируется, весь заявленный функционал работает, код читаем и соответствует стандартам Kotlin (именование, форматирование), обработаны граничные случаи, есть пояснения.
4Задание выполнено, код компилируется и работает, но есть незначительные недочёты: нет обработки отдельных граничных случаев, мелкие отклонения от стандартов оформления.
3Основной функционал работает, но есть ошибки или неполная реализация (часть требований не выполнена), код компилируется.
2Задание выполнено частично: код не компилируется или не работает ключевой функционал.
1Задание не выполнено или выполнено с грубыми ошибками, не относящимися к теме.

Дополнительные критерии: корректность использования конструкций языка и библиотек (Compose, Room, Retrofit, корутины); обработка ошибок и граничных случаев (пустой список, null, сетевая ошибка); читаемость кода и осмысленные имена; наличие краткого пояснения к решению.

Шкала итоговой оценки за комплекс: 4,5–5,0 — «отлично»; 3,5–4,4 — «хорошо»; 2,5–3,4 — «удовлетворительно»; менее 2,5 — «неудовлетворительно».

Задание 1 (базовое). Консольная обработка списка чисел на Kotlin

Формулировка. Разработать консольное приложение на Kotlin, которое принимает от пользователя список целых чисел (через запятую или пробел) и выводит: сумму чисел, среднее арифметическое, максимальное значение.

Требования:

  • использовать функции и коллекции (filter, map, reduce/sum, maxOrNull);
  • обработать пустой ввод и некорректные данные (не числа);
  • код должен компилироваться и запускаться.

Проверяемые умения и навыки: синтаксис Kotlin, работа с коллекциями, функции высшего порядка, обработка ошибок ввода.

Показать пример выполнения 
fun parseNumbers(input: String): List<Int> =
    input.split(",", " ").mapNotNull { it.trim().toIntOrNull() }

fun main() {
    print("Введите числа через запятую или пробел: ")
    val input = readlnOrNull().orEmpty()
    val numbers = parseNumbers(input)

    if (numbers.isEmpty()) {
        println("Список пуст или содержит некорректные данные")
        return
    }

    println("Сумма: ${numbers.sum()}")
    println("Среднее: ${numbers.average()}")
    println("Максимум: ${numbers.maxOrNull()}")
}

Пояснение. mapNotNull отбрасывает некорректные значения, sum/average/maxOrNull дают агрегаты; пустой список обрабатывается отдельно.

Задание 2 (среднее). Android-приложение «To-Do List» на Jetpack Compose

Формулировка. Создать Android-приложение с одним экраном, содержащим список задач. Реализовать: добавление задачи через текстовое поле и кнопку; отображение списка через LazyColumn; удаление задачи по долгому нажатию.

Требования:

  • состояние хранить через remember / mutableStateOf (или rememberSaveable);
  • пустые задачи не добавлять;
  • использовать Material 3 компоненты;
  • код должен компилироваться и запускаться на эмуляторе.

Проверяемые умения и навыки: Jetpack Compose, управление состоянием, LazyColumn, обработка событий, state hoisting.

Показать пример выполнения 
@Composable
fun TodoScreen() {
    var input by rememberSaveable { mutableStateOf("") }
    val tasks = remember { mutableStateListOf<String>() }

    Column(Modifier.padding(16.dp), verticalArrangement = Arrangement.spacedBy(8.dp)) {
        Row(verticalAlignment = Alignment.CenterVertically) {
            TextField(
                value = input,
                onValueChange = { input = it },
                label = { Text("Новая задача") },
                modifier = Modifier.weight(1f)
            )
            Spacer(Modifier.width(8.dp))
            Button(onClick = {
                if (input.isNotBlank()) {
                    tasks.add(input.trim())
                    input = ""
                }
            }) { Text("Добавить") }
        }

        LazyColumn(verticalArrangement = Arrangement.spacedBy(4.dp)) {
            items(tasks) { task ->
                ListItem(
                    headlineContent = { Text(task) },
                    modifier = Modifier.combinedClickable(
                        onClick = {},
                        onLongClick = { tasks.remove(task) }
                    )
                )
            }
        }
    }
}

Пояснение. mutableStateListOf — наблюдаемый список; пустые задачи отсекаются проверкой isNotBlank(); долгое нажатие удаляет задачу через combinedClickable.

Задание 3 (продвинутое). Загрузка данных из сети с отображением состояний

Формулировка. Разработать приложение, которое загружает список пользователей с API https://jsonplaceholder.typicode.com/users, отображает их в списке (имя и email), обрабатывает состояния загрузки и ошибки.

Требования:

  • использовать Retrofit + корутины + Jetpack Compose;
  • смоделировать состояние через sealed-интерфейс UiState (Loading / Success / Error);
  • предусмотреть повторную загрузку при ошибке (кнопка «Повторить»);
  • код должен компилироваться и запускаться; при отсутствии сети отображается сообщение об ошибке.

Проверяемые умения и навыки: Retrofit, корутины, моделирование состояния, обработка ошибок сети, Compose-UI, архитектура MVVM.

Показать пример выполнения (ключевые фрагменты) 
data class UserDto(val id: Int, val name: String, val email: String)

interface UsersApi {
    @GET("users")
    suspend fun getUsers(): List<UserDto>
}

sealed interface UiState {
    data object Loading : UiState
    data class Success(val users: List<UserDto>) : UiState
    data class Error(val message: String) : UiState
}

class UsersViewModel(private val api: UsersApi) : ViewModel() {
    private val _state = MutableStateFlow<UiState>(UiState.Loading)
    val state: StateFlow<UiState> = _state.asStateFlow()

    fun load() = viewModelScope.launch {
        _state.value = UiState.Loading
        _state.value = runCatching { api.getUsers() }
            .fold(
                onSuccess = { UiState.Success(it) },
                onFailure = { UiState.Error(it.message ?: "Ошибка сети") }
            )
    }
}

@Composable
fun UsersScreen(viewModel: UsersViewModel) {
    val state by viewModel.state.collectAsStateWithLifecycle()
    LaunchedEffect(Unit) { viewModel.load() }

    when (val s = state) {
        is UiState.Loading -> CircularProgressIndicator()
        is UiState.Error -> Column {
            Text(s.message)
            Button(onClick = { viewModel.load() }) { Text("Повторить") }
        }
        is UiState.Success -> LazyColumn {
            items(s.users) { user ->
                ListItem(
                    headlineContent = { Text(user.name) },
                    supportingContent = { Text(user.email) }
                )
            }
        }
    }
}

Пояснение. UiState исчерпывающе моделирует три состояния; runCatching обрабатывает сетевые ошибки; LaunchedEffect запускает загрузку при входе на экран; кнопка «Повторить» повторно вызывает load(). В реальном проекте ViewModel создаётся через фабрику с внедрением зависимости UsersApi.
